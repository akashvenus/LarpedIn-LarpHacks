# LarpedIn — working glossary

These terms will become the shared vocabulary for the three workstreams. Definitions marked **open** need confirmation.

| Term | Working meaning |
| --- | --- |
| Event | A Luma-linked professional or technical gathering shown in the app. Its source and metadata are open. |
| Event guide | The in-app sequence of photo prompts while attending an event, including access to the real device camera. |
| Photo checkpoint | One suggested image: room-wide shot, selfie, event banner, or handshake. One actual capture plus three checked prompts complete the demo. |
| Stand-up | A simple form for a short daily update. |
| Post draft | Text assembled from the user's selected cliché hook, event, three learnings, conclusion, and hashtags. |
| AI take the wheel | A button that chooses curated MadLibs selections; it makes no live model or news request in the demo. |
| XP | Session-only progress earned through selected app activities toward a 100-point internship-themed bar. Refresh resets it. |
| Dorm | The first-year room scene that displays the character and earned placeable items. |
| Equippable | A cosmetic item held or worn by the character. |
| Placeable | A cosmetic item assigned to a permitted spot in the dorm. |
| Achievement | A badge for an in-app milestone. |
| Gift-box reward | The animated prize reveal after all guided-demo tasks are complete. It introduces the simulated recruiter message. |
| Recruiter outreach | A prewritten message automatically delivered to a fictional seeded recruiter inside a LinkedIn-like simulation, with no external send or send-button step. |
| Seeded profile | The predefined demo user whose progress lasts until the page is refreshed. |
| Demo session | The in-memory state spanning the app's screens. Refreshing the page starts it over. |
| Simulated social app | An in-app, visibly labeled LinkedIn-like feed and inbox, with no external account or messages. |
